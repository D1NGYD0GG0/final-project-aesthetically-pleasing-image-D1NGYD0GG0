Aesthetically Pleasing Image

## Repository
https://github.com/D1NGYD0GG0/final-project-aesthetically-pleasing-image-D1NGYD0GG0

## Description
I will create an aesthetically beautiful artwork. This is relevant to media and digital arts because it is an exercise in the use of programming to create digital art.

## Features
- Shape
	- I will add multiple shapes through my program.
- Color
	- Using my program I will integrate color into my digital artpiece.
- Shadow
	- Through cell shading / darker color shades I will introduce depth.

## Challenges
- How to create shapes.
- How to incorporate color.
- How to create shapes with lowered opacity.

## Outcomes
Ideal Outcome:
- A detailed portrait of my original character Marley.

Minimal Viable Outcome:
- A simple portrait of my original character Marley

## Milestones

- Week 1
  1. Create base sketch for portrait
  2. Learn how to create shapes and apply them

- Week 2
  1. Decide color palette
  2. Learn how to use color and apply it

- Week 3 (Final)
  1. Decide lighting / angle of shadow.
  2. Learn how to create shapes with lowered opacity and apply them.
